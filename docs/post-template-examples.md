## 6. 一句话解读规则

一句话解读不是固定套话。

它应该每条都根据数据动态生成，但遵循同一套写法：

- 期权异动：解释为什么这笔异动值得看，同时提醒可能是对冲或组合交易。
- 聪明钱调仓：解释持仓变化背后的风格变化，例如更偏防御、成长、能源、AI、现金流。
- 国会交易：解释交易与行业、政策、财报或市场叙事的关系。
- 内幕交易：解释这笔交易为什么比普通股权奖励更值得关注，或为什么要谨慎解读。
- 盘后雷达：总结当天资金最集中的主线和分歧。

好的一句话解读应该做到：

- [ ] 不超过 1-2 句
- [ ] 不喊单
- [ ] 不承诺方向
- [ ] 能说明“为什么值得关注”
- [ ] 能指出一个关键风险或反向解释

## 7. 风险提示规则

频道不能天然做到“每个用户每天首次访问时弹一次风险提示”。

原因：

- Telegram 频道是广播模式。
- 新订阅者可以看到历史消息。
- 普通频道 Bot 不能自动私信每个新订阅者。
- 用户必须先主动打开 Bot，Bot 才能给用户发私信或个性化提醒。

可选方案：

方案 A：每条短提示

```text
⚠️ 仅为公开数据整理，不构成投资建议。
```

优点：最稳妥。  
缺点：每条都有一点占空间。

方案 B：每天第一条提示

```text
⚠️ 今日风险提示：本频道仅整理公开数据，不构成投资建议。期权交易风险极高，披露数据可能延迟。
```

优点：频道更清爽。  
缺点：用户如果没看到当天第一条，后面的单条内容风险提示较弱。

方案 C：置顶公告 + 每条极短提示

置顶公告放完整免责声明，每条只放：

```text
⚠️ 非投资建议
```

优点：兼顾专业和简洁。  
缺点：仍然不是严格意义上的“首次访问提示”。

方案 D：接入 Bot 个性化提醒

用户点击 Bot `/start` 后，Bot 每天第一次向该用户推送内容时，先发送一次风险提示。

优点：可以做到真正的“每日首次提示”。  
缺点：只适用于 Bot 私聊提醒，不适用于公开频道普通浏览。

推荐采用：

- 免费公开频道：方案 C
- 后续付费/自定义提醒 Bot：方案 D

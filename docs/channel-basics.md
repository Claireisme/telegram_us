## 3. 频道简介

### 版本 A：正式版

```text
追踪美股期权异动、聪明钱调仓、国会议员交易、内幕交易和 SEC 披露。

用公开数据看资金动向。

非投资建议。披露数据可能延迟。
```

### 版本 B：更有传播感

```text
美股资金异动提醒。

追踪期权大单、聪明钱调仓、国会议员交易、内幕交易和 SEC 披露。

公开数据整理，非投资建议。
```

### 版本 C：更专业

```text
美股异动雷达｜公开数据驱动的美股资金流追踪。

覆盖期权异动、13F、Form 4、13D/13G、国会议员交易披露。

仅供信息参考，不构成投资建议。
```

最终采用：版本 B。

原因：短、清楚、适合 Telegram 频道简介，不会显得太像机构研报。

## 4. 置顶公告

最终采用置顶公告：

```text
欢迎来到「美股异动雷达」。

这里追踪：

1. 期权异动
大额 Call/Put、成交量/OI 异常、财报前资金异动。

2. 聪明钱调仓
巴菲特、顶级基金、知名投资人 13F 和公开持仓变化。

3. 国会议员交易
美国国会议员及其关联人的公开交易披露。

4. 内幕交易披露
Form 4、13D、13G 等 SEC 文件中的重要变化。

5. 每日盘后榜单
把当天最值得看的资金异动整理成一条。

重要说明：

- 所有内容来自公开披露和市场数据。
- 13F、国会议员交易等信息存在披露延迟。
- 期权异动可能是方向交易、对冲、价差组合或做市行为。
- 本频道不提供投资建议，不承诺收益。

固定标签：
#期权异动 #聪明钱 #国会交易 #内幕交易 #13F #盘后雷达
```

## 5. 固定免责声明

短版，适合放在每条推送末尾：

```text
仅为公开数据整理，不构成投资建议。
```

中版，适合重要推送：

```text
注意：本内容仅基于公开数据和市场数据整理，不构成投资建议。期权交易风险极高，披露数据可能存在延迟、误差或不完整。
```

长版，适合置顶公告/频道介绍：

```text
本频道内容仅基于公开披露、公开市场数据和第三方数据整理，不构成任何投资建议、买卖建议或收益承诺。期权交易风险极高，13F、国会议员交易、内幕交易等披露信息可能存在延迟、误差或不完整。请独立判断，自行承担风险。
```

## 7. 频道视觉方向

关键词：

- 雷达
- 资金流
- 美股
- 黑色/深灰背景
- 绿色上涨、红色下跌、蓝色数据光
- 简洁金融终端风

头像建议：

```text
深色背景，一个雷达扫描圆环，中间是向上的 K 线或美元符号，文字缩写用 USR 或 RADAR。
```

注意：

- Telegram 头像很小，不要放太多字。
- 不建议头像里写完整中文频道名，会看不清。
- 第一版可以先用简洁图标，后面再精修。

## 9. Bot 创建步骤

Telegram 里搜索 `@BotFather`：

1. 发送 `/newbot`
2. 输入机器人显示名，例如：`美股异动雷达 Bot`
3. 输入机器人 username，例如：`us_stock_radar_bot`
4. 保存 Bot Token
5. 把 Bot 加入频道
6. 设置 Bot 为管理员
7. 允许 Bot 发布消息

本地后续需要配置：

```text
TELEGRAM_BOT_TOKEN=你的 Bot Token
TELEGRAM_CHANNEL_ID=你的频道 ID 或 @username
```

安全提醒：

- Bot Token 不要发到公开频道。
- 后续放到 `.env` 文件里，并加入 `.gitignore`。
